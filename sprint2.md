# Sprint 2  

## Qué se hizo  
Durante el sprint se desarrollaron las siguientes tareas:

- Trabajo mediante ramas

- Validación de código funcionando correctamente

## Problemas encontrados  

- Dificultades al relacionar correctamente la entidad Categorías con productos  
- Ajustes necesarios para integrar SweetAlert2 con validaciones existentes  
- Organización inicial del menú hasta lograr una estructura clara  

---

## Solución  

Se revisó el manejo de ramas y Pull Request para evitar conflictos al momento de hacer merge.  
Se realizaron pruebas adicionales para validar la relación entre categorías y productos.  
Se investigó la documentación oficial de SweetAlert2 para corregir errores de integración y asegurar su correcto funcionamiento dentro del sistema.
